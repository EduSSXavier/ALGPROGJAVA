Estruturas de Repetição – For

Estrutura for, laços aninhados, padrões e comparação com while.

Objetivos da Aula

  • Dominar a estrutura for (inicialização, condição, incremento)
  • Comparar for × while
  • Usar for aninhado (tabelas e padrões)
  • Resolver problemas clássicos de laços

1. Estrutura for

Ideal quando sabemos quantas vezes o laço deve repetir:

for (inicialização; condição; incremento) {
    // bloco
}

Exemplo clássico:

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

• int i = 1 → inicialização
• i <= 5 → condição (enquanto for verdadeira)
• i++ → incremento (executado no final de cada volta)

2. Variações úteis

// Contagem regressiva
for (int i = 10; i >= 1; i--) {
    System.out.print(i + " ");
}

// Passo 2 (só pares)
for (int i = 0; i <= 10; i += 2) {
    System.out.print(i + " ");
}

3. for aninhado

Um for dentro de outro é muito usado para tabelas e padrões:

// Tabuada completa de 1 a 5
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 10; j++) {
        System.out.printf("%d x %d = %d%n", i, j, i * j);
    }
    System.out.println("-------------");
}

4. Comparação rápida

EstruturaQuando usar
forNúmero de repetições conhecido
whileCondição mais complexa ou número desconhecido
do-whilePrecisa executar pelo menos uma vez (menus, validação)

Exercícios Práticos

Exercício 1 – Tabuada de um número

Leia um número inteiro e imprima a sua tabuada de 1 a 10 usando for.

Solução sugerida 
import java.util.Scanner;

public class Tabuada {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Digite um número: ");
        int n = sc.nextInt();

        for (int i = 1; i <= 10; i++) {
            System.out.printf("%d x %d = %d%n", n, i, n * i);
        }
        sc.close();
    }
}
Exercício 2 – Triângulo de Asteriscos

Leia um número N e imprima um triângulo de asteriscos com N linhas:
*
**
***
****

Solução sugerida 
import java.util.Scanner;

public class Triangulo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Número de linhas: ");
        int n = sc.nextInt();

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print("*");
            }
            System.out.println();
        }
        sc.close();
    }
}
Exercício 3 – Desafio: Fatorial

Leia um número inteiro N (≥ 0) e calcule o seu fatorial (N!). Exemplo: 5! = 5 × 4 × 3 × 2 × 1 = 120

Solução sugerida 
import java.util.Scanner;

public class Fatorial {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Digite N: ");
        int n = sc.nextInt();

        long fatorial = 1;
        for (int i = 1; i <= n; i++) {
            fatorial *= i;
        }

        System.out.println(n + "! = " + fatorial);
        sc.close();
    }
}
