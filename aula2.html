Estruturas de Controle Condicionais

if, if-else, else-if, operadores relacionais e lógicos. Como o programa toma decisões.

Objetivos da Aula

  • Entender e aplicar if, if-else e else-if
  • Usar operadores relacionais e lógicos corretamente
  • Resolver problemas com decisões simples e compostas
  • Conhecer o operador ternário (introdução)

1. Operadores Relacionais e Lógicos

Relacionais (comparam valores e retornam true ou false):

OperadorSignificadoExemplo
==Igual ax == 10
!=Diferente dex != 0
>Maior queidade > 18
<Menor quenota < 7
>=Maior ou igualx >= 0
<=Menor ou igualy <= 100

Lógicos (combinam condições):

2. Estrutura if / if-else

int idade = 20;

if (idade >= 18) {
    System.out.println("Maior de idade");
} else {
    System.out.println("Menor de idade");
}

O bloco dentro do if só é executado se a condição for verdadeira.

3. Encadeamento else-if

double media = 8.5;

if (media >= 9.0) {
    System.out.println("Conceito A");
} else if (media >= 7.0) {
    System.out.println("Conceito B");
} else if (media >= 5.0) {
    System.out.println("Conceito C");
} else {
    System.out.println("Conceito D");
}

4. Operador Ternário (introdução)

Forma compacta de if-else para atribuições simples:

int idade = 17;
String status = (idade >= 18) ? "Maior" : "Menor";
System.out.println(status);

Exercícios Práticos

Exercício 1 – Positivo, Negativo ou Zero

Leia um número inteiro e diga se ele é positivo, negativo ou zero.

Solução sugerida 
import java.util.Scanner;

public class PositivoNegativo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Digite um número: ");
        int n = sc.nextInt();

        if (n > 0) {
            System.out.println("Positivo");
        } else if (n < 0) {
            System.out.println("Negativo");
        } else {
            System.out.println("Zero");
        }
        sc.close();
    }
}
Exercício 2 – Classificação de Notas

Leia uma nota (0 a 10) e classifique:
A (≥ 9), B (≥ 7), C (≥ 5), D (≥ 3), F (< 3)

Solução sugerida 
import java.util.Scanner;

public class ClassificacaoNota {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nota (0-10): ");
        double nota = sc.nextDouble();

        if (nota >= 9) {
            System.out.println("Conceito A");
        } else if (nota >= 7) {
            System.out.println("Conceito B");
        } else if (nota >= 5) {
            System.out.println("Conceito C");
        } else if (nota >= 3) {
            System.out.println("Conceito D");
        } else {
            System.out.println("Conceito F");
        }
        sc.close();
    }
}
Exercício 3 – Desafio: Tipo de Triângulo

Leia três lados de um triângulo e diga se é Equilátero (todos iguais), Isósceles (dois iguais) ou Escaleno (todos diferentes). Considere que os valores formam um triângulo válido.

Solução sugerida 
import java.util.Scanner;

public class TipoTriangulo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Lado A: ");
        double a = sc.nextDouble();
        System.out.print("Lado B: ");
        double b = sc.nextDouble();
        System.out.print("Lado C: ");
        double c = sc.nextDouble();

        if (a == b && b == c) {
            System.out.println("Equilátero");
        } else if (a == b || b == c || a == c) {
            System.out.println("Isósceles");
        } else {
            System.out.println("Escaleno");
        }
        sc.close();
    }
}
