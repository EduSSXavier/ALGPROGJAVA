Como Executar um Programa Java

Guia prático para rodar seus códigos em Windows, Linux e diretamente no navegador.

Antes de começar

Para executar um programa Java você precisa de:

  • ▹ O JDK (Java Development Kit) instalado — contém o compilador (javac) e a máquina virtual (java)
  • ▹ Um editor de texto ou IDE (Bloco de Notas, VS Code, IntelliJ…)
  • ▹ Ou, se preferir, um ambiente online (sem instalar nada)

Recomendamos o JDK 17 ou superior (LTS). Download oficial: adoptium.net

1. Windows

Passo 1 – Instalar o JDK

1. Acesse adoptium.net
2. Baixe a versão para Windows (x64)
3. Execute o instalador e marque a opção de adicionar o Java ao PATH

Passo 2 – Verificar a instalação

Abra o Prompt de Comando (cmd) ou o PowerShell e digite:

java -version
javac -version

Se aparecer a versão, está tudo certo.

Passo 3 – Criar e executar o programa

1. Crie um arquivo chamado OlaMundo.java com o conteúdo:

public class OlaMundo {
    public static void main(String[] args) {
        System.out.println("Olá, Mundo!");
    }
}

2. No terminal, navegue até a pasta do arquivo:

cd C:\caminho\para\a\pasta

3. Compile:

javac OlaMundo.java

4. Execute:

java OlaMundo

Pronto! A mensagem “Olá, Mundo!” deve aparecer no terminal.

Dica – Usando VS Code

Instale a extensão Extension Pack for Java. Depois é só abrir a pasta, criar o arquivo .java e clicar em “Run”.

2. Linux

Passo 1 – Instalar o JDK

No terminal (Ubuntu/Debian):

sudo apt update
sudo apt install openjdk-17-jdk

No Fedora:

sudo dnf install java-17-openjdk-devel

No Arch:

sudo pacman -S jdk-openjdk

Passo 2 – Verificar

java -version
javac -version

Passo 3 – Compilar e executar

1. Crie o arquivo OlaMundo.java

2. No terminal:

cd ~/caminho/da/pasta
javac OlaMundo.java
java OlaMundo

O processo é idêntico ao do Windows — só muda a forma de instalar o JDK.

3. Ambientes Online (sem instalar nada)

Perfeito para estudar rapidamente ou quando você não pode instalar programas no computador.

Opção A – OnlineGDB (recomendado para iniciantes)

1. Acesse onlinegdb.com
2. No canto superior direito, selecione a linguagem Java
3. Apague o código de exemplo e cole o seu
4. Clique em Run

Suporta entrada de dados pelo terminal (Scanner funciona normalmente).

Opção B – Replit

1. Acesse replit.com e crie uma conta gratuita
2. Clique em “Create Repl” → escolha Java
3. Escreva o código e pressione o botão de play

Opção C – JDoodle

Acesse jdoodle.com/online-java-compiler, cole o código e clique em Execute.

Dicas importantes

  • ▹ O nome do arquivo deve ser igual ao nome da classe pública (ex: classe OlaMundo → arquivo OlaMundo.java)
  • ▹ Java diferencia maiúsculas de minúsculas (Main ≠ main)
  • ▹ Depois de compilar, o arquivo .class é gerado. É ele que a JVM executa.
  • ▹ Se aparecer “comando não encontrado”, o Java não está no PATH. Reinstale marcando a opção correta ou configure manualmente.
