Como usar este material

Cada aula possui objetivos claros, cronograma sugerido, explicações teóricas, exemplos de código e exercícios práticos. Clique no botão Mostrar Resposta para revelar a solução dos exercícios.

Recomendamos que você tente resolver os exercícios antes de ver a resposta. Use o terminal ou uma IDE (IntelliJ, VS Code ou online como Replit / OnlineGDB).
