1. Conceito de Laço

Um laço (loop) permite executar um bloco de código várias vezes enquanto uma condição for verdadeira.

• Contador: variável que controla quantas vezes o laço executa (ex: i = i + 1)
• Acumulador: variável que vai guardando um total (ex: soma = soma + valor)

2. Estrutura while

O teste da condição acontece antes de entrar no bloco:

int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;          // atualização do contador (importante!)
}

Saída: 1 2 3 4 5

⚠ Se esquecer de atualizar a variável de controle → loop infinito!

3. Estrutura do-while

O bloco é executado pelo menos uma vez, e o teste acontece no final:

Scanner sc = new Scanner(System.in);
int opcao;

do {
    System.out.println("1 - Continuar");
    System.out.println("0 - Sair");
    System.out.print("Opção: ");
    opcao = sc.nextInt();
} while (opcao != 0);

System.out.println("Programa encerrado.");

Muito usado para menus e validação de entrada.

4. Exemplo: Soma dos números de 1 a N

Scanner sc = new Scanner(System.in);
System.out.print("Digite N: ");
int n = sc.nextInt();

int soma = 0;
int i = 1;

while (i <= n) {
    soma = soma + i;
    i++;
}

System.out.println("Soma = " + soma);

Exercícios Práticos

Exercício 1 – Contagem e Somatório

Leia um número N e imprima todos os números de 1 até N. Ao final, mostre a soma desses números.

Solução sugerida 
import java.util.Scanner;

public class ContagemSoma {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Digite N: ");
        int n = sc.nextInt();

        int soma = 0;
        int i = 1;

        while (i <= n) {
            System.out.print(i + " ");
            soma += i;
            i++;
        }
        System.out.println("\nSoma = " + soma);
        sc.close();
    }
}
Exercício 2 – Validação de Nota

Peça uma nota ao usuário. Enquanto a nota não estiver entre 0 e 10 (inclusive), peça novamente. Quando for válida, imprima “Nota aceita: X”.

Solução sugerida 
import java.util.Scanner;

public class ValidaNota {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double nota;

        do {
            System.out.print("Digite uma nota (0 a 10): ");
            nota = sc.nextDouble();
            if (nota < 0 || nota > 10) {
                System.out.println("Nota inválida! Tente novamente.");
            }
        } while (nota < 0 || nota > 10);

        System.out.println("Nota aceita: " + nota);
        sc.close();
    }
}
Exercício 3 – Desafio: Jogo de Adivinhação

O programa “pensa” em um número secreto (pode ser fixo, ex: 7). O usuário tenta adivinhar. Enquanto errar, o programa diz “Tente novamente”. Quando acertar, mostra quantas tentativas foram necessárias.

Solução sugerida 
import java.util.Scanner;

public class Adivinhacao {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int secreto = 7;
        int tentativas = 0;
        int palpite;

        do {
            System.out.print("Adivinhe o número (1-10): ");
            palpite = sc.nextInt();
            tentativas++;

            if (palpite != secreto) {
                System.out.println("Tente novamente!");
            }
        } while (palpite != secreto);

        System.out.println("Parabéns! Você acertou em " + tentativas + " tentativa(s).");
        sc.close();
    }
}
