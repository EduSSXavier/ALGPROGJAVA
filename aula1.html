Fundamentos de Lógica + Introdução ao Java

Conceitos fundamentais de lógica de programação, estrutura de um programa Java, variáveis e entrada/saída via terminal.

Objetivos da Aula

  • Compreender o que é um algoritmo e a importância da lógica de programação
  • Conhecer a estrutura básica de um programa Java
  • Declarar e utilizar variáveis dos tipos primitivos principais
  • Realizar entrada e saída de dados via terminal com Scanner e System.out

1. O que é um Algoritmo?

Um algoritmo é uma sequência finita e ordenada de passos que resolvem um problema. Pense em uma receita de bolo ou nas instruções para fazer um café: são algoritmos do mundo real.

Na programação, transformamos esses passos em código que o computador consegue executar. As três estruturas fundamentais da lógica são:

  • ▹ Sequência – passos executados um após o outro
  • ▹ Decisão – escolher caminhos diferentes (if/else)
  • ▹ Repetição – executar blocos várias vezes (while/for)

2. Estrutura Básica de um Programa Java

Todo programa Java começa com uma classe e o método main:

public class OlaMundo {
    public static void main(String[] args) {
        System.out.println("Olá, Mundo!");
    }
}

• public class → declara a classe (nome do arquivo deve ser o mesmo)
• main → ponto de entrada do programa
• System.out.println → imprime texto no terminal e pula linha

3. Variáveis e Tipos Primitivos

Variáveis são “caixas” que guardam valores. Em Java precisamos declarar o tipo:

int idade = 20;
double altura = 1.75;
boolean estudante = true;
char letra = 'A';
String nome = "Ana";   // String não é primitivo, mas é muito usado

4. Entrada de Dados com Scanner

Para ler dados digitados pelo usuário no terminal:

import java.util.Scanner;

public class Entrada {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Digite seu nome: ");
        String nome = sc.nextLine();

        System.out.print("Digite sua idade: ");
        int idade = sc.nextInt();

        System.out.println("Olá, " + nome + "! Você tem " + idade + " anos.");
        sc.close();
    }
}

Exercícios Práticos

Exercício 1 – Olá, Mundo! personalizado

Crie um programa que imprima a mensagem: “Bem-vindo ao mundo Java, [seu nome]!”

Solução sugerida 
public class OlaPersonalizado {
    public static void main(String[] args) {
        System.out.println("Bem-vindo ao mundo Java, Maria!");
    }
}
Exercício 2 – Média de três notas

Declare três variáveis do tipo double com notas fixas (ex: 7.5, 8.0 e 6.5). Calcule a média e imprima o resultado formatado com duas casas decimais.

Solução sugerida 
public class MediaNotas {
    public static void main(String[] args) {
        double nota1 = 7.5;
        double nota2 = 8.0;
        double nota3 = 6.5;

        double media = (nota1 + nota2 + nota3) / 3;

        System.out.printf("Média final: %.2f%n", media);
    }
}
Exercício 3 – Desafio: Dados pessoais

Faça um programa que leia o nome, a idade e a altura de uma pessoa e imprima uma mensagem no formato:
“Nome: Ana | Idade: 22 anos | Altura: 1,68 m”

Solução sugerida 
import java.util.Scanner;

public class DadosPessoais {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Nome: ");
        String nome = sc.nextLine();

        System.out.print("Idade: ");
        int idade = sc.nextInt();

        System.out.print("Altura (ex: 1.68): ");
        double altura = sc.nextDouble();

        System.out.printf("Nome: %s | Idade: %d anos | Altura: %.2f m%n", 
                          nome, idade, altura);
        sc.close();
    }
}
