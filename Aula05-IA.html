Coleções em Java: Listas, Conjuntos e Mapas

⏱ 120 min

Conteúdo da aula

Do array ao ArrayList

O array, visto na Aula 4, resolve bem o caso em que o tamanho da coleção é conhecido de antemão — mas seu tamanho é fixo desde a criação. Quando não se sabe quantos elementos serão guardados, o Java oferece o Java Collections Framework: um conjunto de classes prontas para trabalhar com coleções que crescem e encolhem dinamicamente.

A mais usada dessas classes é a ArrayList<E>, equivalente direta da list do Python: mantém a ordem de inserção, aceita elementos repetidos e cresce conforme necessário. O <E> é um genérico — indica o tipo dos elementos que a lista vai guardar (ex.: ArrayList<Double>, ArrayList<String>), garantindo que o compilador barre a inserção de um tipo incompatível.

trecho ilustrativo
// Antes (Aula 4): tamanho fixo, definido na criacao
double[] notasArray = new double[5];

// Agora: cresce conforme necessario
ArrayList notas = new ArrayList<>();
notas.add(8.5);
notas.add(7.0);
notas.remove(0);
System.out.println(notas.size());

Os métodos mais usados são add() (insere um elemento), get(indice) (lê pelo índice), remove() (remove por índice ou por valor) e size() (quantidade atual de elementos — o equivalente dinâmico do length do array).

HashSet — unicidade de elementos

Quando repetições não fazem sentido para o problema — como uma lista de nomes distintos ou de códigos já processados — a estrutura adequada é o HashSet<E>, equivalente ao set do Python: qualquer tentativa de adicionar um valor já existente é simplesmente ignorada, sem gerar erro.

EstruturaPermite repetição?Mantém ordem de inserção?
ArrayListSimSim
HashSetNãoNão garante

Os métodos principais são add() (insere, ignorando duplicados), contains() (verifica se um valor já está presente) e remove().

HashMap e a nota sobre tuplas

Quando o problema é associar uma informação a outra — um nome a um telefone, um código a uma descrição — a estrutura certa é o HashMap<K, V>, equivalente ao dict do Python: cada valor (V) é guardado sob uma chave (K) única. Os métodos essenciais são put(chave, valor) (insere ou substitui), get(chave) (recupera o valor associado) e containsKey() (verifica se a chave existe antes de tentar recuperá-la).

Por fim, uma nota sobre a tupla do Python (agrupamento fixo e imutável de valores, geralmente de tipos diferentes): Java não tem uma sintaxe embutida equivalente, mas a alternativa idiomática mais próxima, desde o Java 16, é o record — uma forma compacta de declarar uma classe imutável para agrupar dados:

trecho ilustrativo
record Contato(String nome, String telefone) {}

Contato c = new Contato("Ana", "71 99999-0001");
System.out.println(c.nome() + " - " + c.telefone());

Exercícios práticos

EXERCÍCIO 1 — Lista dinâmica de notas

Ler notas digitadas até o usuário digitar -1, guardando em um ArrayList<Double>; ao final, exibir a lista e a quantidade.

ListaNotas.java
import java.util.ArrayList;
import java.util.Scanner;

public class ListaNotas {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        ArrayList notas = new ArrayList<>();

        System.out.println("Digite notas (-1 para parar):");
        double nota = scanner.nextDouble();
        while (nota != -1) {
            notas.add(nota);
            nota = scanner.nextDouble();
        }

        System.out.println("Notas cadastradas: " + notas);
        System.out.println("Quantidade: " + notas.size());
    }
}

EXERCÍCIO 2 — Nomes únicos com HashSet

Ler nomes até o usuário digitar "fim"; armazenar em HashSet<String>; informar quantos nomes distintos foram digitados.

NomesUnicos.java
import java.util.HashSet;
import java.util.Scanner;

public class NomesUnicos {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        HashSet nomes = new HashSet<>();

        System.out.println("Digite nomes (\"fim\" para parar):");
        String nome = scanner.nextLine();
        while (!nome.equalsIgnoreCase("fim")) {
            nomes.add(nome);
            nome = scanner.nextLine();
        }

        System.out.println("Nomes distintos digitados: " + nomes.size());
        System.out.println(nomes);
    }
}

EXERCÍCIO 3 — Agenda de contatos com HashMap

Criar um HashMap<String, String> associando nome → telefone; consultar o telefone de um nome digitado pelo usuário.

AgendaContatos.java
import java.util.HashMap;
import java.util.Scanner;

public class AgendaContatos {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        HashMap agenda = new HashMap<>();

        agenda.put("Ana", "71 99999-0001");
        agenda.put("Bruno", "71 99999-0002");
        agenda.put("Carla", "71 99999-0003");

        System.out.print("Digite um nome para consultar: ");
        String nome = scanner.nextLine();

        if (agenda.containsKey(nome)) {
            System.out.println("Telefone: " + agenda.get(nome));
        } else {
            System.out.println("Contato nao encontrado.");
        }
    }
}
